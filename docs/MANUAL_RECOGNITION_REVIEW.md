# Manual recognition review (Nov22)
New source-linked route: /streaming-demo/manual-review/. Original product demo and existing research players remain intact. Default preserves ten original dialogue/raw lanes and adds latest packed A/R rows; switch to original-only, advanced-only or eight targeted acoustic variants. Public source projection is restricted to 22 windows / 50 exact newer hypotheses / 172 review groups / 993 ranked alternatives, with stable source, transcript and native-receipt hashes; no private object locations or human answers. Original source video is used throughout. Native model anchors are unverified; replay falls back to source-window bounds and warns about omitted packed intervals. All speech tokens can be reviewed (not just highlights), overlapping span boundaries can be selected, and entire passages can be annotated. Candidate order from exploratory frontier is retained; older catalogue order is match-type order, not a calibrated rank. Ordinary-language alternatives remain distinct. No automatic replacement of source evidence.

Browser-local autosave on candidate selection, every manual input and note; draft text is saved but not counted as confirmed. Explicit retain, manual, uncertain, remove and undo. Export structured JSON with exact original text, source and cell hashes, character offsets, frame ranges, decision, ranked evidence and unresolved queue; unreviewed is not negative. Overlapping decisions stay separate. Import accepts only matching dataset and span identities; newest timestamp wins. No network writes, no new inference, no Modal, no GPU, no server-side annotation store. Export before clearing browser storage or changing device. Existing public comparison and video assets are reused, not copied or mutated.
